# Registro de decisiones

| ID | Decisión | Motivo | Condición de revisión |
| --- | --- | --- | --- |
| ADR-001 | Fedora KDE Plasma 45, x86-64 y AMD como primer perfil. | Fedora publicó la edición estable el 3 de noviembre de 2026. RPM, Mock y KDE sobre Wayland cubren las necesidades iniciales. | Revisar el build en VM y la disponibilidad de GPU. Comparar Kubuntu si aparece un bloqueo mantenible o de distribución. [Fedora 45](https://fedoramagazine.org/announcing-fedora-linux-45/) · [Fedora KDE 45](https://fedoramagazine.org/whats-new-in-fedora-kde-plasma-desktop-45/). |
| ADR-002 | Compatibilidad en usuario sobre la ABI Linux. | Mantiene los drivers, las políticas y las actualizaciones del kernel. El uso de NTSYNC pasa por la UAPI existente. | Exigir un caso medido, pruebas de semántica y revisión antes de proponer código de kernel. [UAPI NTSYNC](https://docs.kernel.org/userspace-api/ntsync.html). |
| ADR-003 | C17 y GNU Make para el primer tramo. | El prototipo consta de pocos archivos. Tipos explícitos y `ms_abi` permiten verificar el puente AMD64. | Reevaluar al introducir dependencias transversales o más toolchains. |
| ADR-004 | Implementar primero el contador NT con `CLOCK_BOOTTIME`. | Es un contrato documentado, ejercita NTSTATUS, salidas de 64 bits y un recurso de Linux. Fijar 10 MHz evita exponer un reloj dependiente de CPU. | Validar el subconjunto en Linux y documentar efectos de memoria y suspensión. [Contrato NT](https://learn.microsoft.com/en-us/windows/win32/devnotes/ntqueryperformancecounter). |
| ADR-005 | Ejecutar solo el PE de prueba incrustado. | Verifica código AMD64 real y el puente Microsoft x64 antes de abrir superficies de ejecución. La memoria cambia de RW a RX. | La entrada de PE externos requiere un modelo de amenazas, aislamiento y parser con pruebas de entradas hostiles. |
| ADR-006 | MIT para código propio. Wine y Proton como referencias separadas. | Permite evolucionar el prototipo sin mezclar procedencias. Cada componente distribuido lleva su licencia y su expediente de cumplimiento. | Registrar revisión y obligaciones cuando se elija una integración concreta. [Matriz](reuse.md). |
| ADR-007 | RPM primero, imagen de distribución después. | Un RPM pequeño permite reproducir build, instalación y rollback en VM Fedora antes de cambiar una imagen. | Un RPM firmado y una prueba de instalación permiten iniciar el trabajo de lanzador y escritorio. [Empaquetado](../packaging/fedora/README.md). |
