EAR 0.4.0 — ESTADO VERIFICADO AL 21/10/2026

[SOPORTADO / CODIFICADO]
- Proveedor Bones ModKit ABI 1, rol EAR y version funcional 4.
- Composición DUNGEON en inicio; core sintetiza PCM 22050 Hz mono 16 bits.
- WinMM runtime via carga dinamica; 4 buffers de 512 frames / ~92.9 ms cola.
- after_tick bombea los buffers ya completados; API adicional ear_audio_pump
  lista para invocación de anfitrión por frame si deja de simular ticks.
- Liberación de buffer headers, waveOutReset/Close y FreeLibrary durante stop.
- Error codificado, código nativo, status y reintento manual; falla sin audio.
- Enable music, volúmenes separados, pausa/reanudar waveOut sin reabrir.
- SFX JUMP y LAND: eventos únicos por actor/tick/tipo (ventana 16 claves).
- Compilación Windows diseñada para fuente única: modkit.c incluye auxiliares.

[TESTEADO EN LINUX, NO ES AUDIO REAL WINDOWS]
- GCC -std=c11 -O2 -Wall -Wextra -Wpedantic -Werror.
- Clang C11 con mismos warnings.
- ASan/UBSan del motor de audio con salida simulada.
- Fake playback: apertura, progreso de frames, pause/resume sin nueva apertura.
- Fake no-device: status error y reintento explícito sin crash.
- Headless: indicador unsupported, sin falsa confirmación de hardware.
- Música on/off, SFX independiente, dos eventos únicos + dos duplicados,
  invalid actor, limitaciones de volumen, preferencias antes de inicio,
  start/stop y reinicio sin cerrar/abrir continuamente.
