# Skin — interfaces del Proyecto 1.44

Este directorio reúne el código y la documentación generados por Skin.

- `v0_1/`: primera versión: menús, registro/guardado experimental, tests y demo Win32. La persistencia es prototipo y su atribución de propiedad se revisó posteriormente.
- `v0_2/`: ampliación UI2: componentes de interfaz, capa de composición separada de Eye, inventario, HUD, documentación y pruebas.

> **Responsabilidades actuales:** Skin desarrolla UI/UX, menús, HUD e integración de interfaces. El código de persistencia heredado de v0.1/v0.2 se conserva por trazabilidad, **no** constituye una atribución vigente de autoría sobre guardados.

Fuentes integradas: versiones exportadas en los archivos `PROYECTO_144_Skin_Modulo_v0_1.zip` y `PROYECTO_144_Skin_UI_Integracion_Eye_v0_2.zip` de esta conversación.

Solo fuentes, pruebas, documentación y scripts; se omitieron PNG derivados y una copia repetida del plan maestro. Los artefactos se pueden regenerar con el código y el README de cada versión.

**Integración**: uso de contratos Bones/Eye conforme a la versión; las pruebas en Windows y el presupuesto definitivo de 1,44MB no están certificados.
